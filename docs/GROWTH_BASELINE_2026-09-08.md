# 실제 유입 기준선 — 2026-09-08

## 확인 범위

사용자가 최근 14일 동안 운영자 로그인/점검을 하지 않았다고 확인했다. Codex QA가 시작된 9월 7일 이후와, 운영자 무활동 기간 이전일 수 있는 8월 24일은 제외했다. 기간은 UTC 2026-08-25 00:00부터 2026-09-07 00:00 미만(13일)이다.

조회: `node scripts/growth-baseline.cjs`. 기존 서버 자격으로 읽기 전용 집계. 개인 식별자, 원본 이벤트 행, 메시지/검색 본문은 출력·보관하지 않는다. UA에 bot/spider/crawler/headless/lighthouse가 있는 75개 이벤트를 제외했다. 탐지되지 않는 자동 방문은 남을 수 있다.

## 판단

‘아무도 쓰지 않는 서비스’로 전제할 근거는 없다. 검색엔진에서 들어와 상세를 보고 문의하는 외부 이용 신호가 이미 존재한다. 현재 성장의 첫 축은 검색→연습실 상세→업체 문의다. Instagram은 모집 실험 채널로 유지하되 전체 전략을 여기에만 걸지 않는다. 8마디는 이용자가 있는 것처럼 포장하지 않고 첫 참여와 답마디를 별도 측정한다.

## 이번 대응

1. 검색 조건과 결과 수 정상화, 같은 동 이름이 있는 다른 도시 결과 배제.
2. 연습실 상세의 실제 작동하는 외부 문의 CTA를 모바일 하단에도 제공.
3. 카카오 ID/URL 형식 통합, 유효하지 않은 외부 링크 배제.
4. 작동하지 않는 인원·룸 선택 제거, 예약 가능 시간/최종 가격은 업체 확인으로 명시.
5. 기존 공유 링크의 프로젝트 누락/오류 상태 처리.
6. 유입 UTM을 내부 이동에서도 유지해 향후 문의의 출처를 측정.

## 다음 성과 비교

배포 시점을 기준으로 이후 13일을 같은 정의로 비교한다. 테스트에는 `utm_campaign=codex_qa`를 사용한다. 실제 사람·예약 성사는 자발적 사용자 확인 또는 업체 확인 없이는 확정하지 않는다. 이 보고서의 수치는 이번 작업으로 새로 만든 이용 성과가 아니라 작업 전 기준선이다.
