- middleware.ts (신규)
  로케일 판별 → NEXT_LOCALE 쿠키 저장 → 요청 헤더 x-locale 주입.
  일본어 모드에서 차단 경로 접근 시 홈(/)으로 redirect.

- lib/i18n/locale.ts (신규)
  Locale 타입('ko'|'ja'), LOCALE_COOKIE='NEXT_LOCale'가 아니라 'NEXT_LOCALE', isLocale(),
  JA_BLOCKED_PREFIXES = ['/search','/region','/room','/booking','/my-bookings','/complete','/payment','/partner','/register']

- lib/i18n/index.tsx (신규) — gettext 방식. **한국어 원문이 곧 키**, 사전에 없으면 한국어 폴백(안전).
  · useT(): 클라이언트 컴포넌트용 훅. const t = useT(); → {t('로그인')}
  · t(): standalone 함수. React 밖(alert, lib 함수)용. import { t } from '@/lib/i18n'
  · 변수: t('총 {count}명', { count })  ← 템플릿 리터럴은 이 형태로 변환
  · useIsJapanMode(): 일본 모드 분기용 (연습실 UI 숨김)
  · useLocale(), setLocaleAndReload(locale): 토글용
  · LocaleProvider: app/layout.tsx에서 x-locale 헤더 읽어 주입 완료

- 사전 3파일 (병합되어 DICT_JA가 됨):
